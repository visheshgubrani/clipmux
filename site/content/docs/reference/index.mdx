## The server

- [Environment variables](/docs/reference/configuration): every setting of
  the server, the worker, the CLI and your app's backend.
- [Command line](/docs/reference/cli): `clipmux` and `npx @clipmux/node`.
- [Management API](/docs/reference/management-api): the routes the dashboard
  uses, for scripting a server. They may change between releases.

## The packages

- [@clipmux/node](/docs/reference/sdks/node): the server SDK, route handlers
  and CLI.
- [@clipmux/player](/docs/reference/sdks/player): the `<clipmux-player>`
  element.
- [@clipmux/uploader](/docs/reference/sdks/uploader): the
  `<clipmux-uploader>` element and the headless uploader.

## Releases

[Changelog](/docs/reference/changelog): what changed in each release.

The integration API is also described as OpenAPI 3.1, which every ClipMux
server serves at `/openapi.json` without a credential. This site's copy is
at [/openapi.json](/openapi.json).
